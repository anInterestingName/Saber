## 2. 摘要与目标

### 2.1 摘要

在现有资产管理/提示词管理入口增加图片提示词反推工具。用户只需上传一张图片，页面调用 SpringBlade 后端完成视觉分析，并展示当前租户标签体系中的自动标签、自由视觉描述、正向提示词、负向提示词和固定 JSON。

页面不要求用户输入标签或 JSON，也不直接调用 `fast-staratlas-ai`。

### 2.2 需求目标

1. 提供清晰的图片上传入口和分析进度反馈。
2. 让用户能够查看并复制自动标签、正向提示词、负向提示词和完整 JSON。
3. 同时展示标签结果和自由描述，避免结果只剩抽象标签。
4. 对加载、空结果、依赖失败、分析失败和重复提交提供明确反馈。
5. 复用现有 Vue 3、Element Plus、Axios、权限和国际化规范，不引入新的 UI 框架。
6. 展示本次分析使用的版本化策略提示词，使用户和维护者能够追溯规则升级前后的结果。

### 2.3 非目标

- 不要求用户手动输入标签或固定 JSON。
- 不在本期提供标签编辑、标签新增、标签删除或标签分类管理。
- 不自动保存分析结果为提示词草稿。
- 不把结果直接写入 `blade_ai_prompt`，因为现有提示词模型不包含负向提示词和图片分析字段。
- 不在浏览器端保存 API Key，不直接请求 `fast-staratlas-ai`。
- 不在本期支持批量图片、历史记录、异步任务列表或图片持久化。

## 4. 业务流程

### 4.1 流程说明

- 前置条件：用户已登录，并拥有 `prompt_reverse` 权限；SpringBlade AI 服务可用。
- 触发入口：`资产管理 > 提示词管理`页面的图片反推操作入口。
- 最终结果：结果抽屉展示分析内容，用户可以复制所需字段并关闭抽屉；页面不新增持久化数据。

1. 用户点击图片反推入口。
2. 页面打开上传和结果容器，用户选择一张图片。
3. 页面校验文件基本信息并提交 `multipart/form-data` 到 SpringBlade。
4. 页面显示加载状态并禁用重复提交。
5. 成功时展示标签、自由描述、正向提示词、负向提示词、分析策略版本和 JSON。
6. 失败时展示可理解的错误信息和重新选择/重试入口。

### 4.2 业务流程图

~~~mermaid
flowchart TD
    A([开始]) --> B[进入图片反推入口]
    B --> C{拥有 prompt_reverse 权限?}
    C -- 否 --> D[不显示入口或返回无权限]
    D --> Z([结束])
    C -- 是 --> E[选择图片]
    E --> F{客户端基本校验通过?}
    F -- 否 --> G[提示格式或大小错误]
    G --> Z
    F -- 是 --> H[提交到 SpringBlade]
    H --> I[显示分析中并锁定提交]
    I --> J{请求成功?}
    J -- 否 --> K[显示错误和重试操作]
    K --> Z
    J -- 是 --> L[展示标签、描述、策略版本、提示词和固定 JSON]
    L --> M[用户复制结果或关闭]
    M --> Z
~~~

### 4.3 异常与替代流程

| 编号 | 触发条件 | 系统行为 | 用户提示 | 数据是否改变 |
| --- | --- | --- | --- | :---: |
| EX-001 | 用户无 `prompt_reverse` 权限 | 隐藏入口或后端返回 403 | 无权限使用该功能 | 否 |
| EX-002 | 未选择文件或文件类型不支持 | 不发请求 | 请选择合法图片 | 否 |
| EX-003 | 后端文件校验失败 | 显示后端错误 | 图片不符合要求 | 否 |
| EX-004 | AI 服务超时或不可用 | 保留当前页面状态，允许重试 | 图片分析服务暂不可用 | 否 |
| EX-005 | 返回 JSON 无法展示 | 不显示残缺结果 | 分析结果格式异常，请重试 | 否 |
| EX-006 | 用户重复点击提交 | 只保留一次请求 | 无额外提示或提示正在分析 | 否 |
| EX-007 | 当前租户的分析提示词未发布或已停用 | 展示后端业务错误，不显示残缺结果 | 图片分析规则未发布或不可用 | 否 |

## 5. 功能需求与验收标准

### 5.1 REQ-001 图片反推入口与权限

- 关联用户故事：`US-001`
- 优先级：Must
- 触发入口：提示词管理页面工具栏或等价的资产管理入口。
- 处理规则：
  1. 只有具备 `prompt_reverse` 权限的用户可以看到和使用入口。
  2. 前端隐藏按钮不替代后端权限校验。
  3. 页面不能暴露 fast 服务地址、API Key 或内部 Redis 信息。
- 验收标准：
  - `AC-001`：Given 用户有 `prompt_reverse` 权限，When 打开提示词管理页面，Then 能看到图片反推入口。
  - `AC-002`：Given 用户没有 `prompt_reverse` 权限，When 打开页面或直接访问功能，Then 入口不可用且后端返回权限失败。

### 5.2 REQ-002 单图上传与提交状态

- 关联用户故事：`US-001`
- 优先级：Must
- 处理规则：
  1. 页面一次只选择一张图片。
  2. 支持拖拽或文件选择；首期提示支持 PNG、JPEG、WebP。
  3. 提交前显示图片预览，提交后显示明确的分析中状态。
  4. 请求进行期间禁止重复提交；失败后保留当前图片并允许重新提交。
  5. 页面只调用 `/blade-ai`，不直接调用 fast 服务。
- 验收标准：
  - `AC-003`：Given 用户选择合法图片，When 提交分析，Then 页面显示预览、加载状态且只发送一次有效请求。
  - `AC-004`：Given 用户未选择图片或选择不支持文件，When 尝试提交，Then 页面阻止请求并显示校验提示。
  - `AC-005`：Given 分析请求失败，When 页面收到失败响应，Then 恢复提交能力、保留图片并显示可重试错误。

### 5.3 REQ-003 分析结果展示

- 关联用户故事：`US-002`、`US-004`
- 优先级：Must
- 处理规则：
  1. 标签按分类分组展示，显示标签名称和必要的置信度。
  2. 自由描述单独展示，不与标签列表混为一体。
  3. 正向提示词和负向提示词使用纯文本区域展示，支持长文本滚动和复制。
  4. 警告和不确定项必须可见，不得静默隐藏。
  5. 结果中展示本次标签快照 hash 和分析提示词版本摘要，便于追溯。
- 验收标准：
  - `AC-006`：Given 后端返回成功结果，When 页面展示结果，Then 标签、自由描述、分析提示词版本、正向提示词、负向提示词和警告均可见。
  - `AC-007`：Given 某分类没有识别到标签，When 展示结果，Then 该分类显示为空状态，不伪造标签。
  - `AC-008`：Given 返回包含未覆盖细节，When 用户查看结果，Then 细节显示在自由描述或警告区域。

### 5.4 REQ-004 固定 JSON 与复制

- 关联用户故事：`US-003`
- 优先级：Must
- 处理规则：
  1. 页面提供查看完整固定 JSON 的区域，使用格式化 JSON 展示。
  2. 用户可以分别复制正向提示词、负向提示词和完整 JSON。
  3. 复制成功显示明确反馈；复制失败不清空结果。
  4. JSON 只读展示，首期不支持用户在页面内修改后回传。
- 验收标准：
  - `AC-009`：Given 分析成功，When 用户点击复制正向提示词，Then 剪贴板内容与响应字段一致。
  - `AC-010`：Given 分析成功，When 用户点击复制完整 JSON，Then 剪贴板内容是合法、格式化且完整的 JSON。
  - `AC-011`：Given 当前浏览器不支持剪贴板写入，When 用户点击复制，Then 页面显示失败提示且原结果仍保留。

### 5.5 REQ-005 页面重置与国际化

- 关联用户故事：`US-001`、`US-003`
- 优先级：Should
- 处理规则：
  1. 关闭结果容器后清理本次临时图片和结果，不能带入下一次分析。
  2. 重新打开入口时默认处于未选择图片状态。
  3. 新增中文、英文、日文文案，并与现有路由和权限文案保持一致。
  4. 页面不把图片正文、提示词正文和 JSON 写入 localStorage 或 sessionStorage。
- 验收标准：
  - `AC-012`：Given 用户关闭已完成的结果，When 再次打开图片反推，Then 页面不显示上一次图片和结果。
  - `AC-013`：Given 切换中文、英文或日文，When 打开图片反推入口，Then 主要操作、状态和错误文案均有对应翻译。
  - `AC-014`：Given 用户完成一次分析，When 检查浏览器存储，Then 不存在图片正文、提示词正文或完整 JSON。

### 5.6 REQ-006 分析策略版本展示与管理入口

- 关联用户故事：`US-001`、`US-004`
- 优先级：Must
- 处理规则：
  1. 成功结果显示 `image_prompt_reverse` 的版本号和内容 hash 摘要，不展示完整系统指令。
  2. 完整 JSON 复制结果保留 `analysisPrompt.code`、`versionId`、`versionNo` 和 `contentHash`。
  3. 图片反推抽屉不提供分析策略编辑控件，也不允许用户随请求覆盖系统指令。
  4. 具备现有提示词管理权限的管理员通过 `/asset/prompt` 中的普通草稿、发布和回滚流程维护 `image_prompt_reverse`。
  5. 策略发布或回滚后无需刷新前端静态资源；下一次分析由后端返回实际使用的新版本。
- 验收标准：
  - `AC-015`：Given 图片分析成功，When 用户查看结果，Then 页面显示分析提示词编码和版本号，完整 JSON 含对应版本字段。
  - `AC-016`：Given 普通图片反推用户不具备提示词编辑权限，When 查看结果，Then 只能查看版本摘要，不能编辑或覆盖分析规则。
  - `AC-017`：Given 管理员通过现有提示词管理发布或回滚 `image_prompt_reverse`，When 用户再次分析图片，Then 页面展示后端实际使用的新版本且无需重新部署前端。

## 7. 认证与访问边界

### 7.1 资源归属

本页面不持久化图片或结果。请求和临时结果属于当前登录用户的当前租户上下文，实际租户校验由 SpringBlade 后端执行。分析策略提示词属于现有租户级提示词管理资源，图片反推页面只读取其版本摘要。

### 7.2 当前访问规则

| 操作 | 是否需要登录 | 业务前置条件 | 失败行为 |
| --- | :---: | --- | --- |
| 查看图片反推入口 | 是 | 具备 `prompt_reverse` 权限 | 不显示入口 |
| 提交图片分析 | 是 | 有权限且图片合法 | 401/403/校验错误 |
| 复制结果 | 是 | 当前页面存在分析结果 | 无结果时不显示复制操作 |
| 管理分析策略提示词 | 是 | 具备现有提示词查看、编辑、发布或回滚权限 | 沿用提示词管理页面权限和错误反馈 |

### 7.3 后续权限影响

- 权限资源：`prompt_reverse`。
- 作用域：当前租户用户。
- 不新增独立角色；角色授权由后端菜单、按钮和 API Scope 配置决定。

## 2. 摘要与目标

### 2.1 摘要

第一阶段已经建设 Element Plus 搜索、列表、分页、表单、字典和 CRUD 状态能力，并迁移参数、岗位页面；
第二阶段已经完成 8 个普通 CRUD、报表和只读日志页面的代码开发，当前仍待真实业务、权限、主题和构建验收。
第三阶段在这些能力之上迁移字典、部门、菜单、角色、顶部菜单、用户和代码生成 7 个树表或复杂页面，重点验证
层级数据、授权树、租户联动、用户导入导出和代码生成副作用能否在纯 Element Plus 页面中可靠运行。

迁移保持现有菜单入口、后端接口、数据结构、租户隔离、权限模型和业务结果不变。7 个目标页完成后不得继续使用
`avue-crud` 或 `avue-form`；用户管理当前已有的 Element Plus 搜索和工具栏应纳入最终统一页面，不能长期保留
Element Plus 外壳与 Avue 核心列表混用的过渡状态。

术语说明：本文“第三阶段”仅指 [REQ-2026-001](REQ-2026-001-element-plus-migration.md) 路线图中的
Element Plus 页面迁移第三批次，不是 `doc/guide/Saber-5.0迁移升级指南.md` 中“基础设施层 TS 化”的第三阶段。

### 2.2 需求目标

1. 将字典、部门、菜单、角色、顶部菜单、用户和代码生成 7 个页面迁移为纯 Element Plus 页面。
2. 为非分页层级列表、分页复杂列表、树选择和授权树建立清晰且可复用的页面行为，不重建声明式 CRUD 引擎。
3. 保持新增子项、租户联动、三类角色授权、顶部菜单配置、用户角色配置、导入导出和代码生成行为不变。
4. 解决详情与树选项竞态、授权状态串用、导入失败恢复、内联排序失败和代码生成重复提交等复杂状态问题。
5. 延续前两阶段的视觉密度、权限、主题、响应式和工程门禁，并为第四阶段保留稳定的兼容边界。

| 指标 | 第三阶段基线 | 第三阶段目标值 | 统计口径 |
| --- | ---: | ---: | --- |
| 本阶段使用 `avue-crud` 的目标页面数 | 7 | 0 | 本文 3.2 节目标页静态检索 |
| 本阶段使用 `avue-form` 的目标页面数 | 1 | 0 | 用户导入表单静态检索 |
| 累计纯 `el-table` 迁移页面数 | 至少 10 | 至少 17 | 第一、二阶段页面加本阶段 7 页 |
| 新增运行时依赖 | 0 | 0 | `package.json` 与 `pnpm-lock.yaml` |
| 本阶段页面类型检查通过率 | 不适用 | 100% | `pnpm run type-check` |
| Must 验收标准通过率 | 未建立 | 100% | 本文 AC 与正式验收记录 |
| 多视口、明暗主题视觉覆盖率 | 未建立 | 100% | 1440px、1024px、375px 及浅色/深色截图 |

### 2.3 非目标

- 本阶段不迁移数据权限、API 权限、区域管理和 `src/views/util/` 示例页面；这些内容属于第四阶段或后续专项。
- 本阶段不移除 Avue 包、全局 Avue 注册、Avue 主布局或第四阶段页面仍在使用的 Avue 能力。
- 本阶段不新建通用声明式列配置、动态表单或树形 CRUD 引擎。
- 本阶段不改变菜单动态路由、按钮权限、角色授权、顶部菜单授权和多租户的后端数据模型。
- 本阶段不新增用户注册、启停、离职、冻结、密码策略、导入覆盖策略或字段级数据权限能力。
- 本阶段不修改用户导入模板结构，不新增 CSV 导入、导入预检、错误文件下载或异步导入任务。
- 本阶段不改变代码生成模板、目标语言、生成目录语义、`system=saber3` 标识或后端文件写入方式。
- 本阶段不为代码生成增加预览、差异对比、压缩包下载、撤销或服务端文件回滚能力。
- 本阶段不修改数据库结构、后端接口路径、认证头、Token Cookie Key、租户契约或现有权限码。

## 4. 业务流程

### 4.1 流程说明

- 前置条件：用户已登录，拥有目标菜单和现有操作权限；相关系统、开发工具和字典服务可用。
- 开发准入：REQ-2026-002 的 Must 业务验收、工程门禁及关键兼容问题已完成，或评审形成明确的带风险准入结论。
- 触发入口：系统管理、权限管理或开发工具中的目标菜单。
- 最终结果：用户完成层级维护、授权、用户专项操作或代码生成；失败时保留可恢复状态且不显示虚假成功。

1. 用户进入目标页面，系统按页面契约加载非分页层级列表或分页列表。
2. 用户查询、重置、展开节点、切换分页或选择记录，系统保持列表、选择和加载状态一致。
3. 用户执行 CRUD 或新增子项时，系统加载详情和父级/租户联动选项，校验通过后调用现有接口。
4. 用户执行角色、顶部菜单或用户授权时，系统加载授权树与当前勾选集合，在独立状态中编辑并提交。
5. 用户执行导入、导出、重置、解锁、内联排序或代码生成时，系统执行对应资格检查和明确确认。
6. 成功后刷新必要数据并反馈；失败时恢复控件、保留可重试上下文，不污染其他记录或授权树。
7. 未迁移页面继续按现有 Avue 行为运行。

### 4.3 异常与替代流程

| 编号 | 触发条件 | 系统行为 | 用户提示 | 数据是否改变 |
| --- | --- | --- | --- | :---: |
| EX-001 | 列表或层级树请求失败 | 结束 loading，保留查询条件和重试入口，不显示旧页面结果为新结果 | 复用 Axios 统一错误提示 | 否 |
| EX-002 | 父级、租户、部门、角色、岗位或字典选项加载失败 | 禁止提交依赖该选项的表单，保留重试或关闭能力 | 复用统一错误提示 | 否 |
| EX-003 | 详情请求失败或快速切换记录 | 清空旧详情，仅最后一次有效请求可回填 | 复用统一错误提示 | 否 |
| EX-004 | 新增子项时目标父节点已变化或失效 | 不使用陈旧父节点提交，刷新后要求重新选择 | 提示重新选择父节点 | 否 |
| EX-005 | 授权树或已选集合任一请求失败 | 不开放提交，不展示不完整勾选结果为当前授权 | 允许关闭和重试 | 否 |
| EX-006 | 授权、删除、重置、解锁或生成操作选择数量不符合要求 | 阻止请求并说明需单选或至少选择一条 | 展示明确选择提示 | 否 |
| EX-007 | 保存或授权提交失败 | 保留表单或授权勾选，恢复提交按钮 | 复用统一错误提示 | 由后端事务决定 |
| EX-008 | 顶部菜单内联排序失败 | 恢复最近一次已确认值或重新加载该行，不能保留虚假排序 | 复用统一错误提示 | 由后端事务决定 |
| EX-009 | 租户切换的联动请求乱序 | 仅当前租户的最后一次请求可更新部门、角色和岗位选项 | 无额外提示 | 否 |
| EX-010 | 用户导入文件类型不正确或上传失败 | 上传前阻止错误类型；请求失败保留导入弹窗和重试能力 | 展示文件或接口错误 | 否或由后端事务决定 |
| EX-011 | 用户导出或模板下载被浏览器阻止 | 当前列表状态不变，不显示下载成功 | 允许再次发起下载 | 否 |
| EX-012 | 代码生成失败或后端仅完成部分文件写入 | 不显示成功，不声明前端已回滚；记录后端返回结果并允许人工检查 | 复用接口错误并提示检查目标目录 | 可能 |
| EX-013 | 权限不足、登录失效或跨租户请求 | 隐藏无权限入口；服务端最终拒绝；401 沿用退出流程 | 复用现有权限和登录反馈 | 否 |

## 5. 功能需求与验收标准

### 5.1 REQ-001 统一层级列表与复杂状态

#### 5.1.1 需求说明

- 关联用户故事：`US-001`、`US-002`、`US-003`、`US-004`、`US-008`
- 优先级：Must
- 触发入口：字典、部门、菜单、角色及其他包含树选择的目标页面。
- 前置条件：第一、二阶段列表、表单、行操作和详情状态能力可用。
- 输入：查询字段、层级节点、父级选项、选择项、详情和权限状态。
- 处理规则：
  1. 字典、部门、菜单和角色后端返回非分页树形列表，页面不得伪造分页总数或按前端分页截断树。
  2. 树表使用稳定 `id` 作为行键，并按后端 `children`、排序和查询结果展示层级。
  3. 查询和重置不得把树形结果扁平化；刷新后在数据仍存在时尽量保留合理的展开上下文。
  4. 新增子项必须预填并锁定当前父节点；普通新增必须清除上一次子项新增残留的父节点和值禁用状态。
  5. 父级选择、详情和列表请求分别管理加载与失败状态，旧响应不得覆盖当前记录或当前租户。
  6. 层级页面沿用搜索、列表、行操作和表单视觉骨架，但不为复用而新增声明式 CRUD 配置层。
- 输出：层级正确、状态隔离且可以独立恢复的 Element Plus 树列表和表单。
- 限制：不改变后端树结构、排序逻辑、删除约束和父子校验。

#### 5.1.2 验收标准

- `AC-001`：Given 检查 7 个目标页，When 静态检索，Then 页面不包含 `avue-crud` 或 `avue-form`。
- `AC-002`：Given 字典、部门、菜单或角色列表加载成功，When 展示多级数据，Then `id`、`children` 和排序对应后端结果且无前端分页截断。
- `AC-003`：Given 用户提交或重置层级查询，When 请求完成，Then 匹配节点仍按层级展示且不残留上一次结果。
- `AC-004`：Given 用户从某行点击新增子项，When 表单打开，Then 父级正确预填并锁定，提交值属于该行。
- `AC-005`：Given 用户关闭子项表单后点击普通新增，When 新表单打开，Then 不残留上一次父级、禁用状态或详情数据。
- `AC-006`：Given 父级选项或详情加载失败，When 用户查看表单，Then 不能提交旧选项或旧详情，并可关闭或重试。

### 5.2 REQ-002 字典、部门与菜单维护

#### 5.2.1 需求说明

### 6.1 业务规则

| 规则编号 | 规则 | 适用范围 | 违反时行为 |

| BR-008 | 授权取消不写后端；失败保留勾选；成功才关闭并刷新 | 角色、顶部菜单、用户 | 恢复弹窗状态后重试 |
| BR-009 | 用户密码只在新增时输入和校验，不在列表、详情和编辑中暴露 | 用户管理 | 安全验收不通过 |

## 2. 测试范围

- 测试目标：验证 Saber 标签分类与标签管理页面的查询、分类规则、标签树、层级调整、状态、删除、权限、并发、
  失败恢复、响应式和主题行为符合 REQ-2026-010。
- 测试范围：`/system/tag`、分类表单、标签树抽屉、标签表单、`/blade-system/tag-category/**`、
  `/blade-system/tag/**`、Element Plus 官方组件映射、动态菜单、按钮权限、API Scope 和 route i18n。
- 不测试内容：标签与业务资源绑定、跨租户共享、导入导出、批量操作、拖拽、数据库事务内部实现和后端租户插件内部逻辑。
- 后端专项：表结构、唯一键、事务、锁、异常祖先路径和真实并发串行化由 SpringBlade `TEST-REQ-2026-002` 验证；
  本文只记录前端可观察结果，不用页面测试替代后端验收。

准备要求：

- 优先级：P0
- 关联验收标准：`AC-023`、`AC-024`
- 模块与页面入口：登录后主导航“系统管理 > 标签管理”。
- 前置账号/权限/租户/数据：租户 A 的无权限、只读、分类维护、标签维护角色；存在一条测试分类和标签树。

- 执行方式：手工；切换账号会改变共享登录态，必须串行。
- 测试步骤与预期结果：
  1. 使用无页面菜单权限的角色登录。
     预期：主导航不显示“标签管理”；直接访问 `/system/tag` 不能读取受保护数据。

     预期：分类列表和标签树可查看；新增、编辑、状态和删除入口全部隐藏。
  3. 使用分类维护角色登录。
     预期：只显示已授予的分类动作；标签树只读或入口按 `tag_view` 权限控制。
  4. 保留 `tag_category_add` 按钮但移除 `system:tag-category:create` Scope，尝试新增分类。
     预期：按钮可见但接口被后端拒绝；页面不显示成功，表单保留且列表不新增记录。
  5. 恢复权限并重新登录。
     预期：按钮权限重新加载，无上一角色权限残留。

### TC-002 分类查询、分页、空状态和详情请求隔离

### TC-009 标签状态、叶子删除和失败恢复

- 优先级：P0
- 关联验收标准：`AC-020`、`AC-021`、`AC-022`、`AC-029`
- 模块与页面入口：标签树状态 Switch、删除操作。
- 前置账号/权限/租户/数据：准备启用父子标签和独立叶子；角色有 view/status/delete。
- 依赖：TC-006。
- 执行方式：手工；写操作。
- 测试步骤与预期结果：
  1. 停用父标签并确认影响文案。
     预期：文案说明子标签保存状态不变；成功后完整树刷新，父节点停用、子节点自身状态仍为原值。
  2. 重新启用父标签。
     预期：成功后完整树刷新；页面不绕过分类或其他祖先状态判断宣称子树全部有效。
  3. 尝试删除非叶子父标签。
     预期：前端不发送 remove 请求并提示先处理子标签；后端并发场景返回 `48111` 时保留树。
  4. 删除独立叶子标签。
     预期：确认文案说明编码不可复用；成功后树刷新，分类 tagCount 减少。

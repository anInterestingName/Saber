## 2. 测试范围

- 测试目标：验证 Saber Pro 风格主框架、页容器、查询列表、工作台、记录弹窗、记录抽屉、查看态详情、
  编辑状态链和迁移兼容符合 REQ-2026-011。
- 测试范围：`src/page/index`、主题 Token、公共页面与弹层组件、首页、参数、用户、菜单、监控日志代表页，
  以及全量活动页面弹层清单和静态门禁。
- 不测试内容：后端内部事务、数据库结构、未纳入代表页的业务规则重设计、新增工作台统计接口、移动端原生应用。
- 测试职责：类型检查、构建和静态扫描属于工程检查；登录、权限、租户和完整业务流程默认由用户在目标环境手工执行。

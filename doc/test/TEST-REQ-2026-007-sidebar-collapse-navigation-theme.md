## 4. 测试用例

### TC-001 桌面侧栏边缘折叠与可访问状态

- 优先级：P0
- 关联验收标准：`AC-001`、`AC-003`
- 模块与入口：登录后主布局，混合布局首页。
- 前置条件：管理员已登录；明亮主题；混合布局；菜单折叠设置开启；视口 1440×900。
- 依赖：无。
- 可并行：否；与其他用例共享登录态、导航状态和界面设置。
- 浏览器能力与执行面：Playwright CLI，Chrome 无头模式，same-turn 连续状态。
- 测试步骤与预期结果：
  1. 打开首页，观察侧栏、Logo、顶部栏和边缘按钮。
     预期：侧栏为 216px，圆形按钮跨在侧栏右边界，名称为“收起菜单”，主内容不被遮挡。
  2. 点击“收起菜单”。
     预期：侧栏和 Logo 同步收为 64px，菜单只保留图标，按钮名称改为“展开菜单”且箭头向右。
  3. 将键盘焦点移入按钮并按 Enter。
     预期：焦点环清晰可见，菜单收起，按钮名称切换为“展开菜单”。
  4. 保持按钮焦点并按 Space。
     预期：菜单重新展开，按钮名称恢复为“收起菜单”；按钮包含 `aria-label` 和
     `aria-expanded`，具有稳定 28px 圆形尺寸与 Tooltip。
- 证据要求：展开、收起截图和 DOM 快照。
- 证据/缺陷：[1440px 展开](../../.playwright-cli/TEST-REQ-2026-007/TC-001-1440-expanded.png)、
  [桌面展开](../../.playwright-cli/TEST-REQ-2026-007/TC-001-desktop-expanded.png)、
  [桌面收起](../../.playwright-cli/TEST-REQ-2026-007/TC-001-desktop-collapsed.png)、
  [键盘焦点](../../.playwright-cli/TEST-REQ-2026-007/TC-001-keyboard-focus.png)、
  [Enter 切换快照](../../.playwright-cli/TEST-REQ-2026-007/TC-001-keyboard-enter.yml)；无缺陷。
- 清理要求：测试结束恢复展开；未产生业务数据。
- 实际结果：侧栏、Logo、按钮方向和可访问名称按预期同步变化，内容区无重叠；Enter 收起
  和 Space 展开均通过，焦点保持在按钮上。
- 结果：通过
- 缺陷引用：无

### TC-002 992px 断点与移动侧栏状态隔离

- 优先级：P0
- 关联验收标准：`AC-006`、`AC-007`、`AC-008`
- 模块与入口：主布局首页和“工作台 > 通知公告”。
- 前置条件：管理员已登录；桌面侧栏曾执行收起；菜单折叠设置开启。
- 依赖：`TC-001`。
- 可并行：否；需要连续验证桌面状态、移动状态和路由跳转。
- 浏览器能力与执行面：Playwright CLI，Chrome 无头模式，same-turn 连续状态。
- 测试步骤与预期结果：
  1. 将视口从 1024px 调整到 992px。
     预期：桌面边缘按钮消失，侧栏默认移出视口，顶部出现“展开菜单”，内容占满可用宽度。
  2. 点击顶部“展开菜单”。
     预期：侧栏以 216px 完整宽度打开，Logo 和菜单文字完整，顶部按钮改为“收起菜单”。
  3. 展开“工作台”并进入“通知公告”。
     预期：路由进入 `/desk/notice`，移动侧栏自动关闭，顶部入口恢复为“展开菜单”。
  4. 将视口调整为 375×812，重复打开和关闭。
     预期：主要操作可达，菜单完整显示，不出现 768px 至 992px 区间菜单错误折叠。
  5. 将视口恢复到桌面。
     预期：桌面折叠偏好没有被移动侧栏开关反向解释。
- 证据要求：992px 关闭/打开、375px 关闭/打开、导航后快照。
- 证据/缺陷：[992px 关闭](../../.playwright-cli/TEST-REQ-2026-007/TC-002-992-closed.png)、
  [992px 打开](../../.playwright-cli/TEST-REQ-2026-007/TC-002-992-open.png)、
  [375px 关闭](../../.playwright-cli/TEST-REQ-2026-007/TC-002-375-closed.png)、
  [375px 打开](../../.playwright-cli/TEST-REQ-2026-007/TC-002-375-open.png)、
  [导航后快照](../../.playwright-cli/TEST-REQ-2026-007/TC-002-navigation-closed.yml)；无缺陷。
- 清理要求：恢复桌面视口；未产生业务数据。
- 实际结果：992px 与 375px 均使用顶部入口，移动菜单完整显示，导航后自动关闭，桌面状态保留。
- 结果：通过
- 缺陷引用：无

### TC-003 导航背景、深色主题与动态主色

- 优先级：P1
- 关联验收标准：`AC-004`、`AC-005`
- 模块与入口：主布局和“界面设置”。
- 前置条件：管理员已登录；桌面视口；侧边或混合布局。
- 依赖：无。
- 可并行：否；修改全局主题和主色。
- 浏览器能力与执行面：Playwright CLI，Chrome 无头模式，same-turn 连续状态。
- 测试步骤与预期结果：
  1. 在明亮主题观察 Logo、顶部栏和侧栏。
     预期：三者背景来自同一导航背景 Token，边框仍能区分内容区。

     预期：菜单选中态和主操作同步变绿，导航背景不被硬编码主色覆盖。

- 证据/缺陷：[明亮主题](../../.playwright-cli/TEST-REQ-2026-007/TC-001-desktop-expanded.png)、

  [暗黑自定义主色](../../.playwright-cli/TEST-REQ-2026-007/TC-003-dark-custom-top.png)；无缺陷。
- 清理要求：已通过“恢复默认设置”恢复明亮主题和拂晓蓝。
- 实际结果：导航背景在明暗主题下保持一致，自定义主色正确作用于交互状态。
- 结果：通过
- 缺陷引用：无

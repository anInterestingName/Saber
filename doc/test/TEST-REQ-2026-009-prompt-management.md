## 2. 测试范围

- 测试目标：验证 Saber 提示词管理页面的查询、草稿、变量、未保存预览、发布、停用、版本、回滚、
  复制、删除、权限、并发、失败恢复、响应式和主题行为符合 REQ-2026-009。
- 测试范围：`/asset/prompt`、提示词模块组件、`/blade-ai/prompt/**` 管理接口、动态菜单、按钮权限、
  API Scope、Axios 业务错误处理和 route i18n。
- 不测试内容：模型调用、Feign 运行时业务调用、Token/成本、数据库事务内部正确性、无登录上下文服务身份、
  标签分类、导入导出和跨租户共享。
- 后端专项：后端表结构、发布事务、Feign 和模板引擎内部逻辑由 SpringBlade `TEST-REQ-2026-001` 验证；
  本文只验证其对前端可观察的接口结果和页面恢复。

### TC-001 动态菜单、按钮权限与 API Scope 双轨授权

- 优先级：P0
- 关联验收标准：`AC-025`、`AC-026`、`AC-027`
- 模块与页面入口：登录后主导航；`资产管理 > 提示词管理`，页面标题“提示词管理”。
- 前置条件：准备查看角色、编辑角色、发布角色、无权限角色；租户 A 存在一条可查看测试提示词。
- 依赖：菜单、按钮和 Scope 初始化完成。
- 执行方式：手工；涉及切换账号和共享登录态，串行执行。
- 测试步骤与预期结果：
  1. 使用无权限角色登录。
     预期：不显示提示词菜单；直接访问 `/asset/prompt` 不能取得受保护数据。
  2. 使用只有 `prompt_view` 和 `ai:prompt:view` 的查看角色登录。
     预期：菜单、列表、详情和版本入口可用，所有写操作隐藏。
  3. 使用只有查看和 `prompt_preview`/`ai:prompt:preview` 的角色打开详情和预览。
     预期：可以预览，新增、编辑、复制、删除、发布、停用、回滚不可执行。
  4. 为角色保留 `prompt_publish` 按钮但移除 `ai:prompt:publish` Scope，尝试发布测试草稿。
     预期：按钮可见但接口被后端拒绝；页面不显示成功，列表状态和版本号不改变。
  5. 恢复最小权限配置并重新登录。
     预期：按钮权限刷新，无上一角色残留。
- 证据要求：各角色菜单和按钮截图、发布失败 Network 摘要、角色授权截图；不得包含 Token。

### TC-004 编辑不可变编码与有序变量类型

- 优先级：P0
- 关联验收标准：`AC-006`、`AC-007`、`AC-008`、`AC-009`
- 模块与页面入口：`/asset/prompt` > 编辑 > 变量定义。
- 前置条件：租户 A 存在 `REQ2026009_TC004_VARIABLES` 草稿；编辑角色已登录。
- 依赖：无。
- 执行方式：手工；写操作，独立草稿。
- 测试步骤与预期结果：
  1. 打开编辑并检查编码字段。
     预期：编码只读；update 请求仍携带原编码、字符串 ID 和字符串 `lockVersion`。
  2. 新增 TEXT、MULTILINE_TEXT、NUMBER、BOOLEAN 四种变量，不手工填写文本最大长度。

  3. 清空文本最大长度，使用上移、下移调整顺序，保存后重新打开。

  4. 将含字符串默认值的 TEXT 切换为 NUMBER，并分别确认、取消不兼容值清理提示。
     预期：取消恢复原类型；确认后清空不兼容值和 maxLength，不做隐式转换。
  5. 输入非法变量名、重复变量名、空显示名、文本 maxLength=0 和超过 100 项。

### TC-005 有效预览、缺失值、默认值和示例值

- 依赖：`TC-004` 变量控件可用。

     预期：测试值和上次结果清空，编辑器正文保持不变。

### TC-009 版本分页、当前标记和不可变快照

- 优先级：P0
- 关联验收标准：`AC-018`、`AC-019`、`AC-021`
- 模块与页面入口：共享提示词 > 更多 > 版本历史。
- 前置条件：共享提示词至少存在 V1、V2；查看角色已登录。
- 依赖：`TC-007`、`TC-008`。
- 执行方式：手工；只读，可在共享提示词不发生写操作时执行。
- 测试步骤与预期结果：
  1. 打开版本抽屉并切换分页。
     预期：版本号倒序，分页总数正确，默认选中当前版本并有明确当前标记。
  2. 选择 V1、V2 查看详情。
     预期：名称、编码、来源、说明、发布人 ID、时间、内容哈希、两段正文和变量快照完整且只读。

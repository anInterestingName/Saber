## 2. 测试范围

- 测试目标：验证样式审计门禁、语义 Token、页面分类、公共弹层、松散视觉基线、响应式布局和代表页面行为。
- 测试范围：`src` 活动源码、`style-audit` 工程检查、登录页、主框架、参数管理、角色管理、提示词管理及其公共弹层。
- 不测试内容：后端代码、数据库、生产发布、真实账号权限矩阵、租户隔离、文件生产数据和未在本轮执行的完整业务流程。
